#### 🎮 梦幻西游复刻系统 (DreamQuest System)

**回合制战斗引擎** (`src/game/combat_engine.rs`)
- ✨ 完整的回合制战斗系统，自动按速度排序出手顺序
- 🎯 支持单人和多人混合战斗
- ⚡ Buff 系统：攻击+、防御+、速度+、吸血

- 💰 任务奖励：经验、金币、物品

### 🔧 技术细节

#### 回合制战斗流程

```
Initialize Combat
  → Sort by Speed (高速先手)
  → Loop Until Victory/Defeat
    → Execute Each Character's Action
    → Apply Buffs/Debuffs Effects
    → Update HP/Stats
    → Check End Condition
  → Calculate Rewards
  → Distribute to Party Members
```

#### 贡献度分配公式

```
奖励 = 基础奖励 × (贡献度分数 / 100) × 分配倍数

贡献度分数 = 
  (个人伤害 / 队伍总伤害) × 50% +
  (个人治疗 / 100) × 20% +
  (Buff/Debuff数 / 5) × 20% +
  (无死亡 ? 10 : -5×死亡) × 10%
```
