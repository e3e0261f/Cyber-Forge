# Cyber-Forge / 键盘铸剑大师

Rust 终端挂机铸剑游戏。敲击键盘即是锤打，挂机自动升级，剑可卖、可上架、可被路过仙人买走。

当前版本：**v2.1**

---

## 当前核心玩法（v2.0 ~ v2.1）

- 挂机自然锤击 + 手动敲击加速
- 学徒三工坊（磨剑 / 附魔 / 修复）
- 藏宝阁上架 + 路过仙人竞拍
- 废铁渣积累提升极品率
- 指数级经济与大阶梯锤数锁定
- SHA-256 防篡改存档
- 纯键盘操作

---

## 更新日志

### v2.1
- 布局改为左中右三栏（左背包、中操作台、右藏宝阁）
- 新增 [H] 操作指南弹窗，集中显示全部快捷键
- 退出保护：按 [Q] 二次确认，确认后自动保存当前锻造进度再退出

### v2.0
- 经验改为 1 锤 = 1 经验，成品按品质给固定经验
- 锤击数按境界大阶梯锁定，消除每级跳变焦虑
- 所有升级费用改为透明指数增长并明码标价
- 界面改为半文言极简文案 + 高对比品阶色彩
- 完善 SHA-256 防篡改本地存档

### v1.9.x 主要变化
- 定型黄金五面板布局
- 学徒分工系统（磨剑台 / 附魔阵 / 修复台）
- 33% 锤爆废铁渣 → 永久提升爆率
- 出炉弹窗、藏宝阁详情弹窗
- 一键卖出、背包扩容、风箱升级等基础经营功能
- 大量 UI 与并发安全修复

## 快捷键（当前）

| 按键 | 功能           |
|------|----------------|
| H    | 操作指南       |
| Q    | 退出（需确认） |
| A    | 招募学徒       |
| B    | 扩容背包       |
| S    | 一键卖出废品   |
| F    | 升级风箱       |
| U    | 扩建厢房       |
| E    | 扩建展位       |
| 1/2/3| 分配学徒岗位   |
| P    | 藏宝阁详情     |
| 任意键 | 加速锤击     |
