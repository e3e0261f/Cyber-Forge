非对称签名（Ed25519 算法）：
服务器持有私钥（Private Key），向全服公开公钥（Public Key）。
服务器对每一次重要突破生成签名；前端用公钥校验。即便黑客逆向了整个前端网页代码，他也只能拿到公钥，在数学上绝对无法伪造服务器签名。
信封加密（KEK 保护 DEK）：
业务层运行的加密密钥（DEK）定期轮换；
根主密钥（KEK）存放在物理隔绝的环境变量或安全模块中，实现了真正的“密钥套密钥、真身永不露面”。
