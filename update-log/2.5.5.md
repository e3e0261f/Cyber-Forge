# Cyber-Forge Update Log

## Version 2.5.5

### 1. 系统优化
- **货币互换 CCVT 增益支持**: 将藏宝阁的货币互换按钮（金币与仙玉互换，快捷键 `O` / `o`）从 CCVT（无极阶梯加速引擎）白名单中移除。
- 现在玩家在进行仙玉与金币的互换时，连续按压能够享受无上限的指数级阶梯加速，极大提升了后期货币兑换的体验。

### 2. 代码更新
- `ui/js/step-acceleration-engine.js`: 移除了对 `Btn_o` 和 `Btn_O` 的过滤。
- `Cargo.toml`: 更新版本号至 2.5.5。
