## ✅ P0-2 Juice 屏幕反馈 (完成)

### 修改文件
| 文件 | 修改 |
|---|---|
| `ui/js/world/fx.js` | 新增 `flashes[]` 全屏闪光层、`criticalTexts[]` 大飘字、`comboHalo` 连击聚能光晕、`timeScale` 慢镜头、`triggerBreakthroughJuice()` 渡劫大震 |
| `ui/js/world.js` | 震动改为弹簧式衰减 `shake *= 0.86`；渡劫大震 24px + 白金闪光 + 慢镜头；`resetImpactFX` 清理新特效 |
| `ui/js/input.js` | 连击计数：暴击 +2 / 普通 +1，2 秒未挥锤归零；`fx.setCombo()` 驱动光环 |
| `ui/js/state.js` | 境界变化时派发 `game:breakthrough` 事件（解耦循环依赖），world.js 监听后触发渡劫大震屏 |

### 实现内容

**屏幕震动 (弹簧式衰减)**
- 普通挥锤 4px / 暴击 9px，衰减系数 0.86，低于 0.5 停止
- 渡劫大震 24px，衰减系数 0.93 保持更久 + 巨型双冲击波

**全屏闪光 (Flash Layers)**
- 暴击：金色 0.35α 350ms 衰减
- 渡劫：白金色 0.55α 600ms 衰减
- 优先绘制于背景之上、粒子之下

**慢镜头 (Time Scale)**
- 暴击：0.35x 持续 8 帧
- 渡劫：0.25x 持续 20 帧
- 所有粒子增量乘以 timeScale，最低钳制 0.15

**大飘字 (Critical Text)**
- 暴击：「完美暴击！」42px 粉色黑描边
- 渡劫：「天劫降临」42px 白色 + 「勘破迷障」22px 金色
- 呼吸脉动缩放 + 黑色描边

**连击聚能光晕 (Combo Halo)**
- 2 连开始显示，半径随连击数扩大 (50→130px)
- 颜色渐进：金 `#ffd700` → 10连粉 `#ff4d7a` → 20连白 `#ffffff`
- 呼吸脉动 + 发光阴影 + 连击数字

**解耦架构**: state.js 派发 `window.dispatchEvent(new CustomEvent('game:breakthrough'))`，world.js 监听，避免 state↔world↔input↔state 循环依赖

## ✅ P0-1 音频系统 (完成)

### 新增文件
- `ui/js/audio.js` — 纯 WebAudio 程序化合成音频引擎 (零外部资源)

### 实现内容

**音效合成 (程序化)**
- `playHit()` — 挥锤金属打击音（方波下滑 + 三角波泛音 + 高频噪声）
- `playCrit()` — 暴击挥锤（更高音高 + 谐波亮闪 + 能量爆发）
- `playSwordBorn()` — 神兵诞生（上扬琶音 C5-E5-G5-C6 + 金光扩散）
- `playUpgrade()` — 升级（C-E-G 三连琶音）
- `playBreakthrough()` — 渡劫突破（低音锣 + 深沉雷声 + 高处震荡）
- `playBreakdown()` — 突破失败（低沉失望音）
- `playCoin()` / `playCopper()` / `playJade()` — 三种货币入账音
- `playMelt()` — 熔炼火焰声
- `playList()` — 上架木槌声
- `playUI()` — 弹窗开合滴声
- `playAuctionSold()` — 拍卖成功双音上扬
- `playQuestAccept()` / `playQuestComplete()` — 任务接取/完成
- `playCombatHit()` / `playMonsterDie()` — 战斗命中/怪物死亡

**背景音乐**
- `startBGM()` / `stopBGM()` — 工坊氛围 BGM（低频 drone + 五声音阶慢速琶音），渐进淡入淡出

**技术要点**
- AudioContext 首次用户交互时延迟解锁（浏览器自动播放策略）
- 音效节流 (throttle) 防止高速挥锤爆音
- 标签页隐藏自动暂停 BGM，恢复后自动重启
- 全局音量控制 `setVolume(0~1)`

### 挂接点修改
| 文件 | 修改 |
|---|---|
| `ui/js/app.js` | 导入 audio + `bindAudioUnlock()` 首次交互解锁 + visibility 暂停/恢复 BGM |
| `ui/js/input.js` | `doStrike()` 内根据 `clock.isCrit` 播放打击/暴击音 |
| `ui/js/state.js` | `syncState()` 新旧状态 diff 触发升级/渡劫/货币/神兵诞生音；`toggleModal()` 播放 UI 音；首次同步防抖 |
